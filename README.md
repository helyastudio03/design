# Atelier de composition — tatouage blackwork organique

Outil interactif en une page (`index.html`, aucune installation requise) pour composer visuellement un projet de tatouage dans le style *abstract organic blackwork* (forêt, lune, corbeaux, racines, masses d'encre) avant de le partager avec votre tatoueur.

## Utilisation

1. Ouvrez `index.html` dans un navigateur (double-clic, ou hébergez-le où vous voulez).
2. Choisissez la zone du corps (avant-bras + main, manche complète, dos, mollet...) dans le panneau de gauche.
3. Cliquez sur **Générer une structure de base** pour obtenir en un clic la grande forme qui structure la composition (3 à 5 bandes noires organiques combinées, épaisses et fines) — cliquez sur **Variation aléatoire** pour explorer des variantes proches sans tout recommencer.
4. Pour chaque élément de la palette (masse d'encre, lame, fracture, épines, branches, racines, pin, forêt, lune, corbeau, brume...), utilisez **+** / **−** : chaque clic génère un morceau entier — plusieurs exemplaires (petits, en plusieurs endroits plausibles du corps) d'un coup — plutôt qu'un seul élément à repositionner ; **−** retire le dernier morceau ajouté.
5. Le glisser-déposer reste disponible pour les ajustements ponctuels : glissez pour déplacer, la poignée du haut pivote, la poignée du coin redimensionne, la croix rouge supprime — mais ce ne sont que des retouches secondaires, l'essentiel de la composition se fait via les boutons +/-.
6. Ajustez opacité, teinte, variante, ordre des calques et notes pour le tatoueur dans le panneau de droite.
7. Exportez en PNG pour l'envoyer tel quel, ou sauvegardez/rechargez le fichier JSON pour reprendre le travail plus tard.

Le travail est aussi auto-sauvegardé dans le navigateur (localStorage).
