# Atelier de composition — tatouage blackwork organique

Outil interactif en une page (`index.html`, aucune installation requise) pour composer visuellement un projet de tatouage dans le style *abstract organic blackwork* (forêt, lune, corbeaux, racines, masses d'encre) avant de le partager avec votre tatoueur.

## Utilisation

1. Ouvrez `index.html` dans un navigateur (double-clic, ou hébergez-le où vous voulez).
2. **Page d'accueil** : une galerie de 8 projets complets générés automatiquement s'affiche. Cliquez sur **🎲 Regénérer tout** pour en obtenir 8 nouveaux, puis cliquez sur le projet qui vous inspire — il s'ouvre dans l'éditeur pour la personnalisation. (**🏠 Galerie de projets** dans l'éditeur permet d'y revenir à tout moment sans perdre la composition en cours.)
3. Dans l'éditeur, choisissez la zone du corps (avant-bras + main, manche complète, dos, mollet...) dans le panneau de gauche. **🌲 Générer un tatouage complet** (en haut à gauche, sans confirmation) régénère toute la composition d'un coup ; **🔄 Réinitialiser** repart d'une toile vierge.
4. Pour construire à la main : **Générer une structure de base** donne la grande forme qui structure la composition (3 à 5 grands coups de pinceau courbes, épais et fins, combinés) — **Variation aléatoire** en explore des variantes proches sans tout recommencer. Puis, pour chaque élément de la palette (coupe négative, masse d'encre, lame, éclats, pointe tribale, ornement symétrique, sigil/veines, épines, branches, racines, pin, forêt, lune, corbeau, brume...), les boutons **+** / **−** ajoutent ou retirent un morceau entier (plusieurs petits exemplaires d'un coup, placés automatiquement à des endroits plausibles du corps). La **coupe négative** est spéciale : elle efface réellement le noir jusqu'à la peau sur son passage, pour trancher les masses et fragmenter le paysage comme dans les références du style.
5. Le glisser-déposer reste disponible pour les ajustements ponctuels : glissez pour déplacer, la poignée du haut pivote, la poignée du coin redimensionne, la croix rouge supprime — mais ce ne sont que des retouches secondaires, l'essentiel de la composition se fait via les boutons ci-dessus.
6. Ajustez opacité, teinte, variante, ordre des calques et notes pour le tatoueur dans le panneau de droite.
7. Exportez en PNG pour l'envoyer tel quel, ou sauvegardez/rechargez le fichier JSON pour reprendre le travail plus tard.

Le travail est aussi auto-sauvegardé dans le navigateur (localStorage).
