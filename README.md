# Atelier de composition — tatouage blackwork organique

Outil interactif en une page (`index.html`, aucune installation requise) pour composer visuellement un projet de tatouage dans le style *abstract organic blackwork* (forêt, lune, corbeaux, racines, masses d'encre) avant de le partager avec votre tatoueur.

## Utilisation

1. Ouvrez `index.html` dans un navigateur (double-clic, ou hébergez-le où vous voulez).
2. Choisissez la zone du corps (avant-bras + main, manche complète, dos, mollet...) dans le panneau de gauche.
3. Ajoutez des éléments (masse d'encre, branches, racines, pin, forêt, lune, corbeau, brume) depuis la palette.
4. Sur le dessin : glissez pour déplacer, la poignée du haut pivote, la poignée du coin redimensionne, la croix rouge supprime.
5. Ajustez opacité, teinte, variante, ordre des calques et notes pour le tatoueur dans le panneau de droite.
6. Exportez en PNG pour l'envoyer tel quel, ou sauvegardez/rechargez le fichier JSON pour reprendre le travail plus tard.

Le travail est aussi auto-sauvegardé dans le navigateur (localStorage).
